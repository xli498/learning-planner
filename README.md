# 学习计划助手｜离线静态学习软件

一个不要求注册、不收集数据的单文件学习计划工具。它刻意不把重点放在“填完整计划”，而是把每天的使用路径压缩为：打开今天页、写下下一件事、开始、完成或调整、回到下一件事。

适合需要把长期目标拆成每天行动的人，例如备考国考、省考、考研、四六级，或自定义学习目标。它不提供题库、课程内容、官方考试信息或学习结论；学习内容、日期和资料均由使用者自己填写和核验。

## 快速开始

1. 打开仓库中的 `index.html`，无需安装依赖或注册账号。
2. 首次使用选择目标和每天可用时间，然后在今日页添加第一件任务。
3. 任务数据只保存在当前浏览器的 `localStorage`；换设备前请先导出 JSON 备份。

在线静态部署可直接将仓库根目录作为站点目录；当前仓库尚未启用 GitHub Pages。

## 为什么这样设计

- **先行动，后配置**：首次只需选择目标和每天大概可用时间；科目与资料可在后续补充。
- **首页是执行台，不是后台**：只突出“现在做”的一件任务和今天其余清单，避免同一任务重复出现。
- **快速记录优先**：首页可以只写一句任务，选择 15/30/45/60 分钟，即可加入今天；科目默认选择已有科目，资料、完成标准、步骤和复盘使用可修改默认值。
- **不假装懂你的资料**：模板产生的资料均明确写为“请替换”，不会伪造教材、课程、考试大纲或成绩信息。
- **重要变更可追溯**：延期或卡住时先展示影响预览，确认后才写入；目标切换、导入覆盖也会要求浏览器确认。

## 已实现功能

- 今日执行页：下一件事、进度、今日清单、开始、完成、撤销、延期和卡住。
- 快速任务：一句话创建任务与时长快捷选择。
- 目标起步模板：国考、省考、考研、四六级；模板只创建可编辑的科目与资料占位。
- 资料管理：每科一个主资料、辅助资料、暂停使用，以及任务资料关联。
- 计划调整：延期、拆分或保留原日期；影响预览、原因记录和版本记录。
- 数据安全：仅使用当前浏览器 `localStorage`，支持 JSON 导入和导出，无账号、无同步、无后端。
- 响应式布局：桌面双栏、移动端单列和底部导航。

## 可部署入口

- `index.html`：零依赖单页应用，可直接部署到任意静态站点或本地双击打开。
- `data-model.json`：本地数据结构说明。
- `TEST_EVIDENCE.md`：本轮实测与验收映射。

## 明确的缺点与边界

- 仅使用浏览器 `localStorage`；不联网、不登录、不发送数据。
- **换浏览器、换设备、清除站点数据后不会自动恢复**。需要用户主动导出 JSON，并在新环境导入；这不是云同步产品。
- **无法发送学习提醒**，也不具备日历、通知、闹钟或离线推送能力。
- **不能自动生成可靠学习计划**。系统不会根据考试日期推导官方节点、教材页码、复习进度或成绩概率，任务和完成标准仍需用户判断。
- **模板覆盖有限**：只有四类常见目标，自定义目标需要手动添加科目；模板资料只是占位，不能直接当作真实学习资料。
- **快速记录故意简化**：它默认“完成这件事”、中优先级和通用步骤/复盘。需要可验收的任务时，应在“资料与设置”补充完整任务信息。
- **当前没有跨任务智能排程**：延期/卡住只能按现有的保守调整方式处理，不会自动重算整周或整月负荷。
- **可访问性与兼容性仍未完全验收**：尚未完成真实触控设备、屏幕阅读器、完整键盘流程、5 名目标用户走查和多浏览器回归，不能把当前版本称为生产级或已上线产品。
- 支持目标、考试/阶段日期、每周可用时间、高效时段；它们均为用户输入，考试信息状态固定为“用户自定义 / 待核验”。
- 目标切换二次确认后清空模块、资料、任务，防止旧目标（例如英语听力）残留在国考计划。
- 支持主资料（每科唯一）、辅助资料、暂停并用提醒。
- 任务包含知识点、资料、完成量、步骤、复盘、优先级、预计时长和状态。
- 今日页面突出一个按优先级排序的“现在做”；支持开始、完成、5 秒撤销、延期、卡住、原因、影响预览和确认后版本化重排。
- 支持 JSON 导入/导出、空态恢复与版本记录。

## 本地运行

直接打开 `index.html`，或使用任意静态文件服务。无需构建、无需网络。

## 仓库内容

- `index.html`：可直接打开的完整应用。
- `README.md`：功能介绍、限制和使用边界。
- `data-model.json`：本地数据结构说明。
- `TEST_EVIDENCE.md`：已完成的开发者回归与未完成验收项。
- `acceptance-tests.md`、`PRD.md`：需求和验收参考。

## 隐私说明

应用不包含分析 SDK、账号系统、远程 API、CDN 依赖或后端。所有计划数据存储在浏览器的 `learning-planner-release-v1` 键中。公开部署静态页面不会自动公开任何人的学习计划，但使用者仍应妥善保管导出的 JSON 文件。

## 部署前检查

1. 通过 `TEST_EVIDENCE.md` 中 P0 核心流程。
2. 用目标浏览器复测本地存储、导入/导出与手机触控。
3. 如接入后端，须重新评估隐私告知、数据删除、认证和同步冲突；当前包不包含这些能力。

## 已知边界 / 当前阻塞

- 本包是静态本地 MVP，不含账号同步、提醒、真实考试政策查询、题库或 AI 建议。
- “考试日期是否受影响”仅显示用户已填写日期，不能计算或声称官方考试节点影响。
- 真实发布前仍需进行 PRD 要求的目标用户可用性走查（至少 5 名）；当前仅完成开发者实测，不能替代用户研究。
